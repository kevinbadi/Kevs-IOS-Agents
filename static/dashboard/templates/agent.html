Setup needed

Add a model key to turn agent mode on

Agent mode is powered by a Claude vision model. Put ANTHROPIC_API_KEY=… in your local .env (it is git-ignored, never commit it) and restart the dashboard. Optional: AGENT_VLM_MODEL defaults to claude-haiku-4-5, the cheapest vision-capable model.
